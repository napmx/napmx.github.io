# 하우스애드 사용하기

nap ssp에서 응답할 광고가 없는 경우, 하우스애드 기능을 통해 퍼블리셔의 광고를 노출할 수 있습니다.

파트너 사이트 메뉴: **미디어 > 하우스애드**

이용 방법 문의: nap_adx@nasmedia.co.kr

> 하우스애드를 사용하기 전, nap ssp 파트너 사이트에서 미디어 등록 및 애드유닛 등록이 먼저 완료되어야 합니다.

---

## 하우스애드 지원 범위

| 항목 | 내용 |
|------|------|
| 지원 플랫폼 | Android / iOS / m.web / pc.web |
| 지원 포맷 | **Banner** 전용 |
| 사이즈 | Banner 전체 사이즈 |
| 지원 소재 | 200kb 이하 jpg 파일 또는 HTML 소스 |

---

## 1. 광고소재 등록

1. **미디어 > 하우스애드 - 광고소재 Tab** 에서 **광고소재 등록** 버튼을 클릭합니다.
2. 아래 필수 입력 항목을 입력 후 저장합니다.
   - **광고소재 이름**

---

## 2. 캠페인 등록 및 복사

**캠페인 상태**는 대기, 진행, 종료, 완료의 상태를 가집니다.  
하위 광고그룹/소재 진행 기간에 따라 상태가 변경됩니다.

해당 캠페인의 (on/off 버튼) 클릭 시, 하위 광고그룹/소재 전체가 종료 상태로 변경됩니다.

하위 광고그룹/소재의 상태에 따른 캠페인 상태 변화:
- 하위 광고그룹/소재 전체 '진행' 상태 시 → 해당 캠페인 '진행' 상태
- 하위 광고그룹/소재 전체 '종료' 상태 시 → 해당 캠페인 '종료' 상태
- 하위 광고그룹/소재 전체 '대기' 상태 시 → 해당 캠페인 '대기' 상태
- 하위 광고그룹/소재 전체 '완료' 상태 시 → 해당 캠페인 '완료' 상태
- 하위 광고그룹/소재의 상태가 '종료' 또는 '완료' 상태인 경우 → 캠페인 '종료' 상태 이상

1. **미디어 > 하우스애드 - 캠페인 Tab** 에서 **캠페인 등록** 버튼을 클릭합니다.
2. 아래 필수 입력 항목을 입력 후 저장합니다.
   - **광고소재이름**, **캠페인명**
   - 기존 등록된 캠페인이 없는 경우: '광고소재 새로 등록하기' 버튼을 클릭하여 광고소재 등록
3. 기존 캠페인을 복사하려면 복사하려는 캠페인 선택 후 **캠페인 복사** 버튼을 클릭합니다.  
   복사된 캠페인 확인: 캠페인 이름에 '\_복사'가 추가됨

---

## 3. 광고그룹/소재 등록

1. **미디어 > 하우스애드 - 광고그룹/소재 Tab** 에서 **광고그룹/소재 등록** 버튼을 클릭합니다.
2. 아래 필수 입력 항목을 입력 후 저장합니다.
   - **광고소재** — 기존에 등록된 광고소재 중 1개 선택
   - **캠페인** — 기존에 등록된 광고소재에 연결된 캠페인 중 1개 선택
   - **광고그룹 이름** — 해당 광고그룹의 이름 입력
   - **진행 기간** — 해당 광고그룹의 진행기간 선택
3. 진행 기간 설정 후 광고그룹의 **소재를 등록**합니다.
4. 모든 항목 설정 후 **저장** 버튼을 클릭합니다.

**소재 등록 방법:**
- 소재 유형: 요일/시간대 — 하우스애드를 노출할 요일과 시간대 선택
- 애드유닛 배포: Red — 하우스애드를 노출할 애드유닛 선택  
  (Yellow: 선택한 플랫폼의 애드유닛 목록 확인)
- 소재 업로드 방법 (지원 소재: 200kb 이하 jpg 파일 또는 HTML 소스)

[소재 업로드 > 추가하기] 버튼으로 여러 광고 소재를 등록할 수 있습니다.
