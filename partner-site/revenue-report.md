# 수익화 리포트 확인하기

광고 노출, 클릭, 수익 현황을 확인하는 방법입니다.

파트너 사이트 메뉴: **리포트 > 수익화 리포트**

---

## 리포트 조회

1. **리포트 > 수익화 리포트** 메뉴로 이동합니다.
2. 조회 기간을 설정합니다 (최대 90일).
3. 필터 옵션을 선택합니다.
   - 미디어
   - 애드유닛
   - 플랫폼
   - 광고 네트워크
4. **조회** 버튼 클릭

---

## 리포트 지표

| 지표 | 설명 |
|------|------|
| 노출 수 | 광고가 실제로 노출된 횟수 |
| 클릭 수 | 광고 클릭 횟수 |
| CTR | 클릭률 (클릭 수 / 노출 수 × 100) |
| CPM | 1,000회 노출당 수익 (원) |
| 수익금 | 해당 기간 총 수익 (원) |
| Fill Rate | 광고 요청 대비 광고 노출 비율 |

---

## 리포트 다운로드

리포트를 CSV 형식으로 다운로드할 수 있습니다.

1. 리포트 조회 후 **다운로드** 버튼 클릭
2. CSV 파일로 저장
