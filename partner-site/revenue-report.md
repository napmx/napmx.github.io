# 수익화 리포트 확인하기

광고 노출, 클릭, 수익 현황을 확인하는 방법입니다.

파트너 사이트 메뉴: **리포트 > 수익화 리포트**

이용 방법 문의: nap_mx@nasmedia.co.kr

> 파트너 사이트에 등록된 애드유닛을 사용하여 수익화를 진행하고 있어야 리포트 조회가 가능합니다.  
> 수익화 리포트는 D-1일자 기준으로 제공되며, D-1일자 리포트는 D-day 기준 KST 20시 이후에 최종 확정됩니다.

---

## 1. 수익화 리포트 조회

1. **리포트 > 수익화 리포트** 메뉴로 이동합니다.
2. 조회 기간을 선택하여 수익화 리포트를 확인할 기간을 설정합니다.
3. 원하는 조회 기준을 선택합니다.
4. **검색** 버튼을 클릭하여 리포트를 확인합니다.
5. 필요한 경우 **필터**를 적용하여 조건별로 수익화 리포트를 조회할 수 있습니다.

**조회 기간 조합 안내:**

조회 기간을 1개 선택한 경우, 선택한 조회 기간의 차트로 표시됩니다.  
예) 조회 기간 - 플랫폼 선택 시 → 플랫폼별 차트로 표시

조회 기간을 2개 선택한 경우:
- '일자' 기준이 포함된 경우: 일자 기준의 차트로 표시  
  예) 조회 기간에서 일자&플랫폼 선택 → 일자 기준의 차트로 표시
- '일자' 기준을 제외한 2개 선택 시: 선택한 조회 기준의 하위 기준 차트로 표시  
  예) 조회 기간에서 플랫폼&미디어 선택 → 하위 기준인 미디어 기준의 차트로 표시

---

## 2. 수익화 리포트 CSV 다운로드

우측의 **[CSV]** 버튼을 클릭하여 조회한 리포트를 CSV 파일로 다운로드할 수 있습니다.
