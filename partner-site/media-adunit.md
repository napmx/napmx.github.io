# 미디어 / 애드유닛 등록 및 관리

미디어(앱/사이트)와 광고 단위(Adunit)를 등록하고 관리하는 방법입니다.

파트너 사이트 메뉴: **미디어 > 미디어 관리**

---

## 미디어 등록

1. **미디어 > 미디어 관리 > 미디어 등록** 클릭
2. 미디어 정보를 입력합니다.
   - 미디어 이름
   - 플랫폼: Android / iOS / M.Web / PC.Web
   - 앱 스토어 URL (앱인 경우)
   - 카테고리
3. 등록 완료 후 **Media Key**가 발급됩니다.

> **Media Key**는 SDK 초기화 시 사용됩니다.

---

## 애드유닛 등록

1. **미디어 > 미디어 관리** 에서 대상 미디어 선택
2. **애드유닛 추가** 버튼 클릭
3. 광고 단위 정보를 입력합니다.
   - 애드유닛 이름
   - 광고 포맷: 배너 / 전면 / 네이티브 / 동영상 / 리워드 동영상
   - 광고 사이즈 (배너인 경우)
   - 갱신 주기 (배너 자동 새로고침)
4. 등록 완료 후 **Adunit ID**가 발급됩니다.

> **Adunit ID**는 각 광고 요청 시 사용됩니다.

---

## 네트워크 설정

애드유닛별로 광고 네트워크를 설정할 수 있습니다.

1. 애드유닛 상세 페이지에서 **네트워크 설정** 탭 선택
2. 사용할 네트워크를 활성화합니다.
3. 네트워크별 **비율(Portion)** 및 **우선순위(Priority)** 설정
4. **저장**

---

## 하우스 광고 연결

애드유닛에 하우스 광고를 연결하면 네트워크 광고가 없을 시 (No ads)시 자동으로 하우스 광고가 표시됩니다.
