# 멤버 초대 및 삭제하기

파트너 사이트 메뉴: **계정 > 멤버 관리**

---

## 멤버 초대

여러 명이 동일한 파트너 계정을 관리할 수 있습니다.

1. **계정 > 멤버 관리** 메뉴로 이동합니다.
2. **멤버 초대** 버튼 클릭
3. 초대할 이메일 주소를 입력합니다.
4. 권한 등급을 선택합니다.
   - **관리자**: 모든 기능 접근 가능
   - **편집자**: 미디어/애드유닛 설정 가능, 정산 정보 접근 불가
   - **뷰어**: 리포트 조회만 가능
5. **초대 발송** 클릭

초대받은 사용자는 이메일로 초대 링크를 받습니다.

---

## 멤버 삭제

1. **계정 > 멤버 관리** 목록에서 대상 멤버 선택
2. **삭제** 버튼 클릭
3. 확인 팝업에서 **확인** 클릭

> **주의**: 계정 소유자(Owner)는 삭제할 수 없습니다.
