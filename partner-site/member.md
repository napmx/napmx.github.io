# 멤버 초대 및 삭제하기

파트너 사이트 메뉴: **계정 > 멤버 관리**

이용 방법 문의: nap_adx@nasmedia.co.kr

---

## 멤버 권한

nap ssp 파트너 사이트에서는 **소유자**와 **관리자** 두 가지 권한을 지원합니다.

| 권한 | 설명 |
|------|------|
| **소유자** | [계정] 탭을 제외한 모든 페이지 조회 가능, 수정 및 등록 가능 |
| **관리자** | [계정] 탭을 제외한 모든 페이지 조회 가능, 수정 및 등록 가능. **단, 수익금 신청은 소유자만 가능** |

---

## 멤버 초대

1. **계정 > 멤버 관리** 메뉴로 이동합니다.
2. **멤버 초대** 버튼을 클릭합니다.
3. 초대할 이메일 주소와 권한(관리자)을 입력 후 저장합니다.
4. 초대받은 계정으로 초대 이메일이 발송됩니다.

초대받은 사용자는 이메일을 확인하고 nap ssp 파트너 사이트에 로그인합니다.

- 이미 가입된 이메일인 경우: '로그인하기' 버튼으로 AdMixer SSP 파트너 사이트로 이동 후 로그인
- 아직 가입하지 않은 경우: '회원가입 하기' 버튼으로 가입 후 로그인

> 로그인 시 초대받은 계정으로 페이지 이동이 가능합니다.

---

## 멤버 삭제

1. **계정 > 멤버 관리** 목록에서 삭제할 멤버의 **관리** 열에서 삭제 버튼을 클릭합니다.
2. 삭제가 완료됩니다.

> 소유자 본인은 삭제할 수 없습니다.
