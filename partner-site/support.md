# 문의 및 공지사항, 가이드 확인하기

파트너 사이트 메뉴: **지원센터**

이용 방법 문의: nap_mx@nasmedia.co.kr

---

## 1. 자주하는 질문

**지원센터 > 자주하는 질문** 에서 광고 슬롯에 관한 FAQ를 확인하여 외부 광고 집행 관련 궁금한 사항을 해결할 수 있습니다.

---

## 2. 1:1 문의

**지원센터 > 1:1 문의** 를 통해 '자주하는 질문'에서 확인이 어렵거나 추가적으로 문의하고 싶은 사항에 대해 운영자에게 직접 문의할 수 있습니다.

### 1:1 문의 등록

1. **지원센터 > 1:1 문의 - 1:1문의 tab** 에서 문의 내용을 1:1문의로 등록합니다.
   - **퍼블리셔 이메일**: 1:1문의에 대한 답변을 수신할 이메일 입력
   - **퍼블리셔 연락처**: 퍼블리셔 연락처 입력
   - **미디어명**: 문의할 미디어를 선택 / 등록된 미디어가 없으면 '미디어없음' 선택
   - **첨부파일**: 문의 내용에 대해 추가적으로 전달하고자 하는 파일이 있을 경우 등록
   - **문의 내용**: 문의할 내용에 대해 자세하게 입력
2. 작성 완료 후 **[1:1문의하기]** 버튼 클릭 시 해당 문의 내용이 운영자에게 전송됩니다.

### 1:1 문의 답변 및 현황 확인

**지원센터 > 1:1 문의 - 문의현황 tab** 에서 동일한 문의내용 목록과 현황을 확인할 수 있습니다.  
문의 제목 클릭 시, 문의 내용과 답변 내용을 확인할 수 있습니다.

---

## 3. 공지사항

**지원센터 > 공지사항** 에서 AdMixer SSP에 관한 공지사항을 확인할 수 있습니다.

---

## 4. 가이드

**지원센터 > 가이드** 에서 nap ssp 서비스를 이용하는데 필요한 가이드 목록을 확인할 수 있습니다.  
파트너 사이트 가이드, SDK / Script 연동 가이드, API 연동 가이드 등이 포함됩니다.

---

## 5. ads.txt

**지원센터 > 가이드 - ads.txt tab** 에서 ads.txt에 관한 내용과 적용 가이드를 확인할 수 있습니다.
