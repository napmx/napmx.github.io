# 차단 규칙 등록 및 관리

Admixer 네트워크를 통해 노출되는 광고 소재 중, 원하지 않는 광고를 차단하는 방법입니다.  
계정, 미디어, 애드유닛 단위로 차단 규칙을 적용할 수 있습니다.
**모든 네트워크에 소재 차단 적용이 필요한 경우, nap_mx@nasmedia.co.kr 로 문의 부탁드립니다.**

파트너 사이트 메뉴: **애드리뷰센터 > 차단 관리**

---

## 차단 규칙 정보

차단 정보는 **카테고리** 또는 **Bundle** 중 하나로 설정합니다.

- **카테고리**: 차단을 원하는 광고 카테고리를 IAB 기준으로 선택  
  (1depth → 2depth 순으로 선택. 1depth만 선택 시 정상 반영되지 않습니다.)
- **Bundle**: 차단할 Package name, APP ID, 웹 URL 직접 입력  
  여러 Bundle을 차단하는 경우 `,`로 구분하여 입력  
  예) `com.admixer,1234567,www.admixer.com`

---

## 1. 차단 규칙 등록

1. **애드리뷰센터 > 차단 관리 - 차단 규칙 관리 Tab** 에서 **규칙 추가** 버튼을 클릭합니다.
2. 차단 규칙 설정 시 아래 필수 입력 항목을 입력 후 저장합니다.
   - **차단 규칙 이름**: 차단 규칙의 이름 입력
   - **차단 적용 방법**: 미디어, 애드유닛, ALL 중 선택
     - 미디어: 선택한 미디어 하위에 등록된/등록될 모든 애드유닛에 차단 규칙 적용
     - 애드유닛: 선택한 애드유닛에 차단 규칙 적용
     - ALL: 계정에 등록된/등록될 모든 미디어의 모든 애드유닛에 차단 규칙 적용
   - **차단 규칙 정보**: 카테고리 또는 Bundle 중 하나 설정
3. 모든 항목 저장 후 **저장** 버튼을 클릭합니다.

---

## 2. 차단 규칙 활성 ↔ 비활성 설정

등록된 차단 규칙에 대해 활성 ↔ 비활성 상태 변경이 가능합니다.

- **차단 관리 - 차단 규칙 관리 Tab** 에서 변경할 차단 규칙의 **상태** 열에서 토글 버튼을 클릭합니다.
  - 활성 상태: 차단 규칙 적용 중
  - 비활성 상태: 차단 규칙 미적용

---

## 3. 차단 규칙 삭제

- **차단 관리 - 차단 규칙 관리 Tab** 에서 삭제할 차단 규칙의 **관리** 열에서 **규칙 삭제** 버튼을 클릭합니다.
- 규칙 삭제 시 해당 규칙에 연결된 미디어 및 애드유닛에 대한 차단 규칙 적용이 모두 해제됩니다.

---

## 4. 광고 차단 현황

**애드리뷰센터 > 차단 관리 - 광고 차단 현황 Tab** 에서는 차단된 애드유닛의 정보 및 차단 상세 정보를 확인할 수 있습니다.

**차단 관리 - 차단 규칙 관리 Tab** 에서 '활성' 상태인 차단 규칙이 적용된 애드유닛의 정보가 제공됩니다.
