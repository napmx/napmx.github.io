# 차단 규칙 등록 및 관리

특정 광고주, 카테고리, 도메인의 광고를 차단하는 방법입니다.

파트너 사이트 메뉴: **애드리뷰센터**

---

## 차단 규칙 유형

| 유형 | 설명 |
|------|------|
| 광고주 차단 | 특정 브랜드/광고주 광고 차단 |
| 카테고리 차단 | 특정 업종 광고 전체 차단 (예: 도박, 성인) |
| 도메인 차단 | 특정 랜딩 URL 도메인 차단 |
| 크리에이티브 차단 | 특정 광고 소재 차단 |

---

## 차단 규칙 등록

1. **애드리뷰센터 > 차단 규칙** 메뉴로 이동
2. **차단 규칙 추가** 클릭
3. 차단 유형 선택
4. 차단 대상 입력 (광고주명, 카테고리, 도메인 등)
5. 적용 미디어/애드유닛 선택
6. **저장**

> **참고**: 차단 규칙 적용까지 최대 30분이 소요될 수 있습니다.

---

## 광고 심사 요청

부적절한 광고가 노출된 경우 광고 심사를 요청할 수 있습니다.

1. **애드리뷰센터 > 심사 요청** 메뉴 이동
2. 문제 광고 스크린샷 및 URL 첨부
3. 사유 입력 후 제출
