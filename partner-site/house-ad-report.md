# 하우스애드 리포트 확인하기

하우스애드 노출 현황을 확인하는 방법입니다.

파트너 사이트 메뉴: **리포트 > 하우스애드 리포트**

---

## 리포트 조회

1. **리포트 > 하우스애드 리포트** 메뉴로 이동합니다.
2. 조회 기간 및 대상 미디어/애드유닛을 선택합니다.
3. **조회** 버튼 클릭

---

## 리포트 지표

| 지표 | 설명 |
|------|------|
| 노출 수 | 하우스애드가 노출된 횟수 |
| 클릭 수 | 하우스애드 클릭 횟수 |
| CTR | 클릭률 |
| 하우스애드명 | 노출된 하우스애드 소재명 |
