# 비즈보드

{% hint style="info" %}
비즈보드는 Kakao Adfit의 프리미엄 광고 포맷입니다. 일반 Adfit 배너와 다른 별도의 심사 및 코드 발급 절차가 필요합니다.
{% endhint %}

---

## 비즈보드란?

카카오 비즈보드는 앱 사용자에게 최적화된 디자인으로 맞춤형 프리미엄 광고를 제공하는 Adfit 전용 광고 포맷입니다. 철저한 소재 심사를 거쳐 높은 퀄리티의 광고가 노출됩니다.

---

## 비즈보드 지면 정책

{% hint style="warning" %}
**비즈보드 사용 시 필수 정책**
1. **단독 사용 필수**: 비즈보드 지면은 비즈보드만 단독으로 사용해야 합니다. 다른 네트워크 미디에이션과 함께 사용할 수 없습니다.
2. **심사 필수**: 앱 내 비즈보드 테스트 광고가 적용된 지면의 스크린샷을 운영팀에 전달하여 심사를 받아야 합니다.
{% endhint %}

---

## 연동 절차

### Step 1: 비즈보드 코드 발급

운영팀(nap_mx@nasmedia.co.kr)에 문의하여 비즈보드 코드를 발급받으세요.

### Step 2: 리포트용 애드유닛 발급

1. nap ssp 파트너 사이트에서 새 애드유닛 생성
   - 이름: `비즈보드` (또는 식별 가능한 이름)
   - 포맷/사이즈: **Banner - 320x50** 선택
2. 애드유닛 발급 후 운영팀에 해당 애드유닛의 **비즈보드 리포트 매핑** 요청

### Step 3: SDK 연동

Adfit 비즈보드 공식 가이드를 참고하여 연동합니다.

* [Adfit Android 비즈보드 연동 가이드](https://github.com/adfit/adfit-android-sdk/blob/master/docs/BIZBOARDAD.md)

### Step 4: 지면 심사 신청

SDK 연동 후 테스트 광고가 정상 노출되는 지면 스크린샷을 **nap_mx@nasmedia.co.kr**로 전송하여 심사를 신청하세요.

```
[비즈보드 심사 흐름]
연동 테스트 → 테스트 광고 노출 확인 → 스크린샷 전달 → 매체 심사 → 상용 광고 송출
```
